# ViMoA Project Page

Official project page for **ViMoA: Vision-Motion-to-Action Flow Matching for Visual Navigation**.

## Local preview

From the repository directory, run:

```powershell
python -m http.server 8000
```

Then open `http://localhost:8000/`.

## GitHub Pages

This site is published from the `main` branch of the `vimoa-nav/vimoa-nav.github.io` repository.

The public URL is `https://vimoa-nav.github.io/`.
