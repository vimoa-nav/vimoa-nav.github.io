ViMoA: Vision-Motion-to-Action Flow Matching for Visual Navigation

Abstract

Diffusion models and flow matching have emerged as promising generative paradigms for waypoint generation in visual navigation. However, existing methods typically generate local waypoints from Gaussian noise or separately constructed prior trajectories. Gaussian noise differs substantially from feasible trajectory distributions, while inaccurate prior trajectories can degrade generated trajectory quality. We propose ViMoA, a latent flow matching policy that fuses visual context and recent motion history into an informative source latent for navigation action generation. To bridge the representation gap between task-informed source features and low-dimensional waypoint actions, ViMoA represents future actions as latent features matching the source dimensionality, enabling flow matching in a shared latent space. Since the source already contains navigation-relevant visual and motion information, it provides an informative initialization for transport toward future actions and eliminates repeated condition injection during flow integration. To improve navigation safety, ViMoA incorporates traversability constraints into both visual representations and waypoint constraints. The enhanced visual representation improves obstacle awareness, while the waypoint constraint penalizes predictions in regions with low traversability. Experiments in simulated and real-world environments show that ViMoA achieves higher navigation success, fewer collisions, and better trajectory quality than prior methods.

Method
